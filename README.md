Image Editing App with Streamlit & OpenCV

Project Description
This project is an interactive image editing application built using Streamlit and OpenCV. Users can upload images, apply filters, preview changes, and download edited images.

Features
- Blur Filter
- Sharpness Adjustment
- Brightness Control
- Contrast Adjustment
- Edge Detection
- Grayscale Conversion

Technologies Used
- Python
- Streamlit
- OpenCV
- NumPy
- Pillow

Installation
bash
pip install -r requirements.txt
